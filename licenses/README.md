# License material

`FAST-LIVO2-LICENSE.txt` points to the GPL-2.0-only license text supplied with the vendored FAST-LIVO2 source. Other notices generated for Python and vcpkg environments are kept with packaged distributions under `_internal/licenses/`.

`Spirula-Studio-SOURCE.md` records the provenance and source location of the bundled Spirula
Studio binary (GPL-3.0; the license text is the same as `GPL-3.0.txt`). `OpenMVS-SOURCE.md` does the
same for the bundled OpenMVS programs (AGPL-3.0). `SOURCE.md` says where the
corresponding source of every GPL program in a release is published.
