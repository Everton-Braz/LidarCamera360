# Posting guide: LinkedIn, Facebook, X

Platform limits change. If something is rejected, check the platform's help page and update this file.

## Which asset where

| | X | LinkedIn | Facebook |
|---|---|---|---|
| Best image | `banner_1200x675.jpg` (16:9) | `banner_1080x1350.jpg` (4:5, more feed height) | `banner_1080x1350.jpg` |
| Video | 16:9 MP4, ≤ 2:20, ≤ 512 MB | 16:9 or 4:5 MP4, 3 s–10 min, ≤ 5 GB | 16:9 MP4 in feed; 9:16 for Reels |
| Text limit | 280 chars (a link always counts 23) | 3,000 chars; ~210 show before "…see more" | very long allowed; ~125 show before "See more" |
| Hashtags | 1–2 | 3–5, at the end | 0–3 |
| Link | in the first reply (posts with links get less reach) | in the post or first comment | in the post |

H.264 video with AAC audio, 30 fps, works on all three. Burned-in captions help: most people watch muted.
Post the video **natively** (upload the file), never as a YouTube link.

## X (x.com)

1. x.com → **Post** (left bar).
2. Paste the hook post (≤ 280 chars, no link). Click the media icon, add the video *or* up to 4 images
   (1200x675). Add alt text to each image ("Add description").
3. Post. Open it, click **Reply**, paste the link reply: GitHub release URL + one line.
4. Optional thread: reply to your own reply with 2–4 short feature posts, one image each.
5. Pin the post to the profile (⋯ → Pin to your profile) until the next release.

## LinkedIn (personal profile)

1. linkedin.com → **Start a post**.
2. Paste the post. The first two lines are the hook: they must make sense alone before "…see more".
3. Media icon → add the video or the 4:5 banner. For the video, add a thumbnail (the 1080x1350 banner works) and
   an SRT caption file if you have one.
4. Hashtags at the end (3–5). Tag people or companies only when they are actually involved.
5. **Post**. Then add the GitHub link as the first comment (optional; some people prefer the link in the post).
6. If you have a company page: on the page, **Create** → **Start a post**, or repost your personal post with one
   line of your own on top.

## Facebook (page or profile)

1. On the page: **Create post** (switch to the page profile first if you manage it from your personal account).
2. Paste the post; the link can stay in the text. Facebook builds a link preview: remove the preview (×) when you
   attach your own image or video, or the media is replaced by the preview.
3. Add the video or the 4:5 banner.
4. Post. Share it to relevant groups (LiDAR, mobile mapping, photogrammetry, 3DGS) only where the group rules allow
   tools and releases; write one personal line per group, do not paste the same text.
5. Reels (optional): a 9:16 cut of the film, ≤ 90 s, with the link in the caption.

## Timing and follow-up

- Tuesday to Thursday, 8–10 h in the audience's main time zone. One platform after another within ~1 hour.
- Answer every comment in the first hour.
- One week later: a follow-up post with a real result (a dataset, a before/after) rather than repeating the release.

## Tone

Direct and technical. Say what changed and what it fixes, with real numbers only when measured. No "game changer",
no "revolutionary", no emojis as bullets. Known limitations are fine to mention; they build trust.
Never mention other products.
