## LinkedIn (attach the film, or banner_1080x1350.jpg)

```
A LiDAR + 360° camera calibration is only right for the capture it was made on.
LidarCamera360 v0.4.0 checks and refines it on every capture.

What's new:
→ Rig profiles v2: one file describes the scanner and every camera (model, intrinsics, mount), with a New rig wizard and "Validate on a capture".
→ Per-capture refinement: time offset and mount are refined by multi-view colour consistency and kept only when held-out frames agree.
→ Insta360 ONE RS 1-inch 360: select both INSV files and process them as one capture.   [ONE RS]
→ Clean clouds: --remove-dynamic removes moving and standing people; each view colours only points scanned near its capture time.
→ .lc360 project package, and an export command for PCD, LAZ/LAS, GeoJSON, GPS tracks and trajectories.

One honest note: north derived from imagery can pass the quality gates and still be wrong, so check georeferenced results before relying on them.

Free for Windows: zip bundle or a single portable .exe, no ROS, WSL or Linux setup.
Release notes and download: https://github.com/Everton-Braz/LidarCamera360/releases/tag/v0.4.0

#LiDAR #MobileMapping #PointCloud #GaussianSplatting #360Camera
```
