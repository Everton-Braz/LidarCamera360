# LidarCamera360 — Hermes Project Rules

Hermes: quando trabalha neste repositório, siga estas regras.

## Build & Ambiente

- **Python 3.10+** (projeto roda em 3.11/3.13 — verificar antes de rodar).
- Deps de runtime: `requirements.txt`. Deps de build: `requirements-build.txt`.
- Instalar runtime: `pip install -r requirements.txt`.
- Instalar build: `pip install -r requirements-build.txt`.
- App principal: `lidarcamera360.py` (entry point).
- App Raven (Insta360 X4 + 3DMakerPro Raven): `raven.py`.
- Build com PyInstaller: `tools/build_windows.ps1` (PowerShell).
- **Sem ROS necessário** — processamento nativo de `.bag` ROS1 em Windows.

## Teste

- Suite: `pytest tests/ -v`.
- Smoke do pacote: `tests/smoke_packaged.py`.
- Testes de calibração: `tests/test_calibration_math.py`, `tests/test_basemap.py`.
- Testes GPS/INSV: `tests/test_insv_gps.py`, `tests/test_gps_workflow.py`.
- Testes de viewer: `tests/test_viewer_*.py`.
- Antes de declarar uma mudança feita: rodar `pytest tests/ -x` (fail fast).

## Projeto

- **LidarCamera360**: fusão LiDAR + câmera 360° (dual-fisheye), SLAM in-process FAST-LIVO2, calibração de rig, colorização Vulkan.
- **Raven** (predefinição): 3DMakerPro Raven + Insta360 X4, +18.5 cm braço de alavanca vertical (`configs/rig_profile.json`, `FAST-LIVO2/config/raven.yaml`).
- **Eagle** (predefinição): 3DMakerPro Eagle + Insta360 X6, protocolo Livox CustomMsg (`configs/rig_profile_eagle.json`, `FAST-LIVO2/config/eagle.yaml`).
- Configs de rig: `configs/rig_profile.json` (Raven), `configs/rig_profile_eagle.json` (Eagle).
- Extrinsics determinados: `extrinsics_determined.json`.

## Worker backend — Antigravity CLI (`agy`)

- O CLI `agy` (Antigravity) está disponível como worker de execução / revisão de terceira opinião.
- Verificar disponibilidade: `agy --version` e `agy models` (via terminal).
- Modelo padrão para revisões: `Gemini 3.8 Flash (High)`.
- Uso não interativo (one-shot):
  ```
  agy -p '<prompt>' --model "Gemini 3.8 Flash (High)" --print-timeout 30s
  ```
- Para revisão de diff/segurança: `agy -p 'Review this diff for bugs and security issues' --model 'Gemini 3.8 Flash (High)'`.
- Adicionar contexto extra: `--add-dir <path>` (repetible).
- Saída é **texto puro** — sem envelope JSON.
- `agy help` mostra comandos wrapper (`install`, `plugin`, `update`); as flags interativas (`/config`, `/permissions`, `/model`) só existem dentro de uma sessão TUI.
